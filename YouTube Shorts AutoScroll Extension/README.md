# YouTube Shorts AutoScroll (Chrome Extension)

This extension auto-advances to the next YouTube Short as soon as the current one finishes.

## Install (Developer mode)
1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this folder: `YouTube Shorts AutoScroll Extension`.
5. Open any `https://www.youtube.com/shorts/*` URL.

## Notes
- Works only on YouTube Shorts pages.
- No external permissions or network access are required.
